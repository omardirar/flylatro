# ADR 0013: Flylatro source licence and reproducible dependency lock

Status: accepted.

## Decision

**Flylatro's own source code is MIT licensed** (`LICENSE`). MIT was chosen
deliberately rather than copied from any dependency: the repository is research
software whose value is in being reproducible and reusable by other labs, and a
permissive licence removes friction from reuse, re-analysis and replication. The
choice is recorded here so it can be revisited before publication; it is a
project decision, not an inherited one.

The licence covers this repository's source only. It explicitly does **not**
cover and this repository does **not** redistribute:

- FlyWire FAFB v783 / Codex connectome data (user-supplied, own terms);
- Balatro, which is proprietary and used only as a user-owned installation;
- the pinned `balatroagent` simulator, under its own upstream licence;
- any third-party Python dependency, each under its own licence.

Third-party licensing is documented separately in `docs/DEPENDENCIES.md`.

**Dependency lock.** `uv.lock` pins the full resolved dependency graph,
including the pinned `balatro-sim` git revision, with hashes. It is generated by
`uv lock` and committed. `pyproject.toml` remains the authority for declared
ranges; the lock is the reproducibility record for a specific environment. A
lock refresh is a deliberate, reviewable change, not a side effect of an
install.

Continuous integration is deliberately out of scope for this decision.

## Consequences

Publishing the repository requires no further licence decision. Re-resolving
dependencies requires `uv lock` and a commit, so an experiment's software
environment stays addressable alongside its artifact and report hashes.
